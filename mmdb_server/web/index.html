    How it works

    Where the answers come from, what they mean, and the licences of the software and data behind this page.

    From routing data to an answer

    1. Routing and registration data

      Networks announce their address ranges on the Internet through BGP. Each announcement is matched with the whois record of the range and of its autonomous system.

    2. GeoOpen databases

      CIRCL turns this data into two open databases in the MaxMind DB format, rebuilt on a regular basis: GeoOpen-Country and GeoOpen-Country-ASN.

    3. Lookup

      mmdb-server finds the range that holds the address in every loaded database. The answer is a JSON array, one object per database, with the country information added.

    4. This page

      The page calls the same public API as curl does, merges the answers and draws the country on the map. It needs no account and keeps nothing.

    What a result means

    The country is where a network is registered or announced, not where a device or a person is. A range used in several countries, a VPN or a cloud provider can give a country far from the real location. No city or street-level data is provided.

    Privacy

    Your address is never looked up by itself: only when you click My address. Scripts, icons, flags and country shapes are served by this server: no CDN, no tracker. If the administrator set a map tile server, the map background is loaded from it: it receives the map area you view, never the address you look up.

    Licences

    Every library, icon set, flag and typeface is a pinned copy served by this server from static/vendor/. Map tiles, when enabled, come from the tile server set by the administrator. Click a licence to read the file shipped with it.
